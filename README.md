# 🏫 Bright Future School

A modern, responsive school website built with **HTML, CSS, and JavaScript**. The website presents school information, courses, admissions, a gallery, and contact options in a clean, user-friendly design.

## 🌐 Live Demo

**[Visit Bright Future School](YOUR-LIVE-WEBSITE-URL)**

> Replace `YOUR-LIVE-WEBSITE-URL` with your actual GitHub Pages link.

## ✨ Features

- 📱 Responsive layout for desktop and mobile devices
- 🧭 Navigation menu with mobile support
- 🌙 Dark mode with saved theme preference
- 🏫 School introduction and statistics
- 📚 Courses and admissions sections
- 🖼️ Image gallery
- 📢 Announcement banner
- ✉️ Contact form with validation and confirmation feedback
- 💬 WhatsApp contact button
- ⬆️ Back-to-top button
- ✨ Scroll reveal animations

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Git and GitHub
- GitHub Pages
